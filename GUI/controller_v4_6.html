RPM compares wheel speeds. Applied % is the actual command sent to each Sabertooth input. Correction % is the straight-line PI adjustment (active only at ≥12% equal-speed commands). Counts accumulate encoder edges; 4480 counts ≈ one motor-output revolution. Reset fault clears a latched stall after inspection; it does not reset counts.
